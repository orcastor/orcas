OrcaS v0.2.1 修复加密文件夹集成升级时的两个兼容性问题，保留 v0.2.0 的安全加固与存储改进。

## 修复

- 使用同一个读写锁保护运行时加密密钥的读写，修复文件属性请求与文件夹解锁、锁定并发时的数据竞态。
- FUSE 文件和目录使用挂载进程的 UID/GID，确保启用 `default_permissions` 时，非 root 用户仍可写入新目录。
- 发布检查加入并发密钥读取与切换的竞态回归测试。

v0.2.0 的部署配置与迁移要求继续适用，详见 [v0.2.0 发布说明](https://github.com/orcastor/orcas/releases/tag/v0.2.0)。

## English

- Protect runtime encryption-key reads and writes with the same read/write lock, fixing races between filesystem requests and encrypted-folder lock/unlock operations.
- Report the mounting process's UID/GID for FUSE objects so non-root mounts using `default_permissions` can write to newly created directories.
- Include the concurrent key-read/switch race regression in the release gate.

Linux amd64 and arm64 CLI archives and `SHA256SUMS` are provided. The deployment requirements introduced in v0.2.0 still apply.

**Full changelog:** https://github.com/orcastor/orcas/compare/v0.2.0...v0.2.1
