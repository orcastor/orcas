# OrcaS v0.2.2

Released on November 20, 2026. This maintenance release updates the cache, ID generation, and content hashing dependencies used by OrcaS.

## Dependency updates

- Upgrade `github.com/orca-zhang/ecache2` from v0.0.1 to v0.1.1.
- Upgrade `github.com/orca-zhang/idgen` from its September 2022 revision to v0.1.1.
- Upgrade `github.com/zeebo/xxh3` from v1.0.2 to v1.1.0 and its CPU detection dependency, `github.com/klauspost/cpuid/v2`, from v2.2.7 to v2.2.10.
- Remove the unused `github.com/orca-zhang/ecache` dependency and refresh module checksums.

## Validation and downloads

The release workflow builds and vets all packages on native Linux amd64 and arm64 runners, then runs the race-enabled SDK, security, compression, VFS metadata and encryption-key switching, buffered-write, cache, journal, and metadata regression checks in `scripts/ci.sh`.

Downloads include Linux amd64 and arm64 CLI archives and `SHA256SUMS`. The deployment requirements introduced in [v0.2.0](https://github.com/orcastor/orcas/releases/tag/v0.2.0) continue to apply. See [the CI documentation](https://github.com/orcastor/orcas/blob/v0.2.2/docs/ci.md) for the scope of the release checks and the known limitations of the wider legacy integration and stress suite.
